# Choosing a Linux, Windows or storage VPS

Start with the workload: the operating system your application requires, its normal memory use, disk growth and transfer needs. A larger plan is useful only when it addresses a resource your workload needs.

| Family | Questions to resolve before ordering | Listing |
| --- | --- | --- |
| Linux VPS | Which distribution and version? How much memory does the application need? Who will maintain the server? | [Linux plans](https://aioffer.shop/en/hosting/linux-vps) |
| Windows VPS | Does the application require Windows? What version, licensing and remote access are included? | [Windows plans](https://aioffer.shop/en/hosting/windows-vps) |
| Storage VPS | Is the workload primarily file storage? Are the disk type, capacity and transfer suitable? | [Storage plans](https://aioffer.shop/en/hosting/storage-vps) |

## Resource checklist

- **Memory:** include the operating system, application, database and background jobs. Measure normal use and leave capacity for traffic peaks and maintenance.
- **CPU:** check core allocation and whether the intended workload fits the plan's usage rules.
- **Storage:** compare capacity and disk type; a large storage plan is not automatically the best choice for a database.
- **Transfer:** check the monthly allowance separately from port speed. A fast port does not imply unlimited traffic.
- **Operations:** confirm location, operating system, access method, backups and who is responsible for updates.
